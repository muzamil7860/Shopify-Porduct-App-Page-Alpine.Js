# Shopify Product App Page Created By Alpine.Js

## Overview

This **Shopify Product Showcase App** is a visually engaging and interactive landing page designed for Shopify merchants. It allows customers to explore a product (in this case, a sweater), choose different color variations, and easily add the item to their cart. The design incorporates smooth animations using Alpine.js for real-time color selection and product image changes.

## Features

- **Interactive Product Display**: Dynamic product image changes based on selected color.
- **Color Variations**: Users can switch between color options for the sweater (Brown, Gray).
- **Mouse-Driven Animation**: Hovering or moving the mouse across the page animates the product image and decorative boxes.
- **Add to Cart Button**: Users can easily add the selected product to their cart with a simple button.
- **Responsive Design**: Optimized for mobile and desktop use.
- **Modern Styling**: Stylish layout with floating decorative icons and image transitions.

## Tech Stack

- **HTML5**: For the structure of the landing page.
- **CSS3**: For styling the page and layout elements.
- **Alpine.js**: A lightweight JavaScript framework for managing the interactive product display and color variations.
- **JavaScript**: For adding mouse-driven animations to the page elements.
- **Responsive Design**: Ensures a seamless experience on both desktop and mobile devices.

## Usage

1. **Product Showcase**: The landing page displays a product image (a sweater) with a heading and subheading.
2. **Color Variation Selection**: Below the product image, color circles are displayed for different variations (Brown, Gray). When a user clicks on one of these color circles, the product image updates accordingly.
3. **Mouse Animations**: As users move their mouse across the page, the floating decorative boxes and product image move smoothly, creating a dynamic experience.
4. **Add to Cart**: Users can click the "Add to Cart | $40" button to simulate adding the product to their cart.

## Mouse-Driven Animation

This project includes a mouse-driven animation effect that moves elements based on the user's cursor position:

- **Floating Boxes**: Decorative boxes with dollar and rectangle icons move when the user moves their mouse.
- **Product Image**: The product image shifts in response to mouse movement, adding a 3D effect to the user experience.

You can adjust the movement strength in the JavaScript code by modifying the `boxMovementStrength` and `imageMovementStrength` values.
